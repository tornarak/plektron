The pane stays *outside* `#stack` for its own reason — everything in that script indexes `STACK.children` as cards, and a pane among them would be pinned and closed like one. **The column still collapses when it is idle** — no cards, the pane shut, and the contents not asked for; the third condition is `#toc-switch` checked, or `.side-contents` on ``, which the head script sets from the sitting's memory before first paint so the column does not appear and jump on every page load. **The fringes override both ways**: `#side-off` checked hides the column whatever it holds, `#side-on` holds it open however empty — or `.side-dismissed` and `.side-open`, which the same head script sets from the sitting's memory before first paint. The stylesheet's rule is the one that must agree with this comment. `pane` asks for the map pane.
