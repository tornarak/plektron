# Terms a general English dictionary cannot be expected to carry, added so the
# lexicon_miss detector reports transcription candidates rather than vocabulary.
#
# Scope: among the detectors this file suppresses `lexicon_miss` and NOTHING ELSE.
# The inventory, apostrophe-adjacency, dot-above-g and smart-quote detectors never
# consult it. A term listed here is still flagged if it carries a marked glyph,
# which is what keeps a whitelist from becoming a hole in the firewall.
#
# It also closes a line-end hyphen the corpus is silent on, through
# `detectors.resolve_break_hyphens`, which refuses any token with a marked glyph
# before it asks.
#
# Do NOT add Chukchi, Koryak or Yupik forms. Those are the signal.
# Matching is case-folded, on hyphen/apostrophe-split components of a token.
#
# **Proper nouns are not kept here.** They are entries in `entities/`, whose
# canonical names and trigger forms `detectors.entity_forms` reads back into
# this dictionary — one file per name, saying which page first attested it,
# instead of a bare line in a list nothing can audit. `harness lexicon misses`
# prints what the entity store accounts for under `suppressed`, so the second
# source is visible rather than silent.
#
# Eleven author names stayed behind at the time, under a heading saying that no
# page in `gt/ocr/` attested them, so `entity new --since` had no witness and the
# entry could not honestly be filed. They have since moved too, and the way they
# moved is the record of why `since:` was removed: every one of the eleven is the
# author of a work listed in Authorities Quoted, `edition/authorities.json` had
# adjudicated all of them, and the store now carries a `source:` entry per work
# with the surname as an alias. The gate was refusing entries on the strength of
# a field rather than of the evidence.
#
# One term per line; `#` starts a comment. Seed the list from real counts with
#     uv run harness lexicon misses
