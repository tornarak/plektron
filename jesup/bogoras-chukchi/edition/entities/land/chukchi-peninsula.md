## gloss

The northeastern tip of Asia, between the Chukchi and Bering Seas.
[[person:bogoras]] travels there in 1900–01 (1-021).

The `area:` is Natural Earth's own `CHUKCHI PENINSULA` region polygon. It used
to sit beside a `geo:` point that had stood in for the boundary before the
polygon existed; the point is gone, because a record now carries a shape or a
point and never both — the shape *is* the location, and `extent_of` would never
have read the point anyway. Natural Earth carries `Q1002` for the same feature,
which is what corrected the `wikidata:` link here: it had read `Q193527`, the
facial bone.
