# Terms a general English dictionary cannot be expected to carry, added so the
# lexicon_miss detector reports transcription candidates rather than vocabulary.
#
# Scope: this file suppresses `lexicon_miss` and NOTHING ELSE. The inventory,
# apostrophe-adjacency, dot-above-g and smart-quote detectors never consult it.
# A term listed here is still flagged if it carries a marked glyph, which is
# what keeps a whitelist from becoming a hole in the firewall.
#
# Do NOT add Chukchi, Koryak or Yupik forms. Those are the signal.
# Matching is case-folded, on hyphen/apostrophe-split components of a token.
#
# **Proper nouns are not kept here.** They are entries in `entities/`, whose
# canonical names and trigger forms `detectors.entity_forms` reads back into
# this dictionary — one file per name, saying which page first attested it,
# instead of a bare line in a list nothing can audit. `harness lexicon misses`
# prints what the entity store accounts for under `suppressed`, so the second
# source is visible rather than silent.
#
# What is left below under a proper-noun heading is the residue of that move:
# names no page in `gt/ocr/` attests, so `entity new --since` has no witness to
# name and the entry cannot honestly be filed yet. They suppress nothing today —
# the detector only ever runs over adjudicated ground truth — and are kept
# against the pages still to be keyed.
#
# One term per line; `#` starts a comment. Seed the list from real counts with
#     uv run harness lexicon misses
