On moll-121, entries 33 and 36 both looked like `рыратык` when read off the
full marked page in sequence (a run of `рырат-`/`рыраты-` derivatives, 33
through 42). Cropped together, entry 33 is `рырататык` (extra `-та-`) and 36
is `рыратык`. Two different words, three rows apart, sharing a long stem and
an identical ending — exactly the shape that hides the difference at 1x.

This is the same fault as [[what-settles-a-letterform]]'s "resolves by
comparison" case (moll-073, `к'эютэкичгын`/`к'эюутэкичгын`), just found on a
different page. **How to apply:** whenever a page runs several consecutive
entries on one derivational stem (here `рыра-`/`рырат-`, eleven entries in a
row), don't trust a headword that "matches" one you already read a few rows
back — crop the two into one frame and compare them character for character
before keying either. A run this long is not eleven independent readings, it
is one long chance for the same substitution to repeat unnoticed.
