On moll-033, entry 16 (`гыарэты`) contains a second bold phrase `гыарэты
вальын` set mid-paragraph, followed by its own sense numbers (1), 2)) and a
`см.` cross-reference, all still inside the same numbered bracket as entry 16
and with no `←` wrap marker and no flush-left placement. This is the book's
way of giving a derived/inflected form its own mini-gloss inside one entry,
not a second headword.

**Why:** the skill's rule for what begins an entry is explicit — "a bold
headword set flush to the left margin" — and bold-but-indented text doesn't
qualify, however word-like and cross-referenced it looks.

**How to apply:** when a numbered bracket contains bold text that is not at
the flush-left margin, keep it inside the gloss cell verbatim (don't split
into a second row, don't strip the boldness distinction — the table has no
bold markup anyway, so it's invisible in the output, but the row count must
stay at one).
