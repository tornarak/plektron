On moll-067, three glosses were read correctly off the raster but keyed wrong:
`коры́то` → `кры́то` (a syllable dropped while typing), `меховы́е` → `мехово́ые`
(letters transposed/added), `балова́ться` → `бразова́ться` (a plausible-looking
but wrong word substituted outright, not a partial misread of any letter on the
page). None of these were doubt at the raster — the zoom crop was unambiguous
each time — so [[what-settles-a-letterform]] and [[gloss-side-faults]] don't
cover them: those are about what the *scan* doesn't resolve, this is about what
the *hand copying it* introduces.

**Why this matters:** a typo that happens to form a real, plausible Russian
word is exactly the fluent-nonsense failure this whole pass exists to avoid,
and it is invisible to every check that compares your row against a prediction
count or a suffix pattern — those only see the headword. The gloss is already
established as nearly unwatched ([[gloss-side-faults]]); a self-introduced typo
there is even less likely to be caught than a dropped accent, because it can
look like ordinary, well-formed prose.

**How to apply:** before finalizing, re-read your own written table cell
against the zoomed crop still on screen, word for word — not just "does this
look like plausible Russian" but "does this string match what the image
showed." Do this especially for glosses containing several similar three-to-four
syllable Russian words in a row (as `моль` runs of near-synonyms like
`шали́ть, ба́ловаться, озорнича́ть` invite), where the eye is primed to expect
one and can substitute it for another mid-type.
