On moll-096, entry 42 ("ок! эй! ок, како! а, да!") is set in one uniform bold
weight across the whole line, headword and gloss alike, with no italic
portion at all — because the entry has no parenthetical clarification. This
looked at first like a layout fault (gloss normally reads as lighter/roman),
but a side-by-side 4x comparison against an ordinary entry (moll-096:37,
"ойн'эмтэк I повали́ть (чело-века, живо́тного)") showed the *main* gloss word
"повали́ть" is exactly as bold as the headword "ойн'эмтэк" — the weight
difference only shows up in the italic parenthetical clarification
"(чело-века, живо́тного)", which is a separate, lighter typeface.

**Why:** the book's typeface convention is headword bold + main gloss bold
roman, with italic reserved for parenthetical notes — not headword
bold + gloss roman/light as I initially assumed from short exposure.

**How to apply:** don't treat a fully-bold short entry (no parenthetical) as
evidence of a misread bracket or an inverted-band artifact. Compare against a
same-scale crop of an entry that *does* have a parenthetical before
concluding the weight is anomalous.

See [[bracket-faults]] for other things a bracket's *contents* can turn out
to be.
